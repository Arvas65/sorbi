# SorBI — tam kurulum (çekirdek + RAG + arayüz).

# Bu dosya geriye dönük uyumluluk içindir: README'deki `pip install -r requirements.txt`
# komutu çalışmaya devam eder. Sürümler requirements/ altında katman katman pinlenmiştir.
#
#   requirements/core.txt      pipeline — LLM ve arayüz olmadan koşar
#   requirements/rag.txt       vektör bağlam (Chroma + embedding); kurulmazsa

#   requirements/ui.txt        Streamlit arayüzü

#   requirements/drivers.txt   PostgreSQL / MySQL sürücüleri (opsiyonel)
#
# Pinleri güncellemek için (requirements/*.in dosyalarını düzenledikten sonra):
#   uv pip compile requirements/all.in --universal --python-version 3.10 -o requirements/all.txt
#   for k in core rag ui dev drivers; do \
#     uv pip compile requirements/$k.in --universal --python-version 3.10 \
#       -c requirements/all.txt -o requirements/$k.txt; done
#
# all.txt tek sürüm kaynağıdır; katmanlar ona kısıtlanır, böylece çelişen pin oluşamaz.
